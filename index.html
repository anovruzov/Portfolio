Current focus

Founder / Mycelic

Memory should belong to the network, not a central database.

Mycelic is a local-first memory architecture for networks of AI agents. Instead of copying everything everywhere, agents preserve useful knowledge through lineage, independent support, selective sharing, and targeted reconstruction.

The broader goal is infrastructure where intelligence can remain distributed while still becoming more capable as a whole.

03

Research thesis

Can an Agentic Web preserve useful knowledge without universally replicating it?

Most shared-memory architectures get reliability by centralizing state or copying it broadly. I’m exploring a different direction: knowledge that stays local, carries its provenance, and can be reconstructed when parts of the network disappear.

Current paper: The Mycelial Web: Self-Healing Collective Memory for the Agentic Internet.
